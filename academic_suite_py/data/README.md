# PAGGY Demonstration Corpus

The records in `demo_scholarly_sources.json` are synthetic metadata fixtures
created exclusively for testing and demonstrating PAGGY's retrieval, similarity,
and reporting workflow.

They are not verified scholarly publications and must not be presented as live
academic-database results.

The data contains no complete copyrighted papers and no private user content.

If the repository already contains a project license, the synthetic fixture data
may be distributed under the same repository license.
